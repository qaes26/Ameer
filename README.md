# مبادرة حكاية الشمال 🇯🇴
> **«حكايتنا، وهويتنا، ومستقبلنا»**  
> مبادرة شبابية سياحية تُبرز جمال وتراث شمال الأردن وتمكّن طاقات الشباب، برؤية سمو ولي العهد المعظم الأمير الحسين بن عبدالله الثاني.  
> **رئيس المبادرة:** عامر الخوالدة

---

## 🏛️ عن المبادرة
مبادرة وطنية شبابية سياحية تنطلق على مستوى شمال المملكة الأردنية الهاشمية (إربد، عجلون، جرش، والمفرق)، تهدف إلى:
- التعريف بالكنوز والمواقع الأثرية، الطبيعية، والتاريخية لشمال الأردن.
- إعطاء الشباب فرصة حقيقية للمشاركة في تطوير السياحة المستدامة وخدمة المجتمع.
- إحياء الهوية والتراث الثقافي ونقل رواية الأجداد بأسلوب رقمي عصري.
- دعم الاقتصاد المحلي والمجتمعات الريفية عبر الترويج للحرف اليدوية والمطابخ الإنتاجية.

---

## 🎨 الهوية البصرية والتصميم
- **الألوان الرسمية:** متناسقة بدقة مع الشعار والبوستر الرسمي (الأزرق الملكي الداكن `#060e1d` / `#0a192f` مع تدرجات الذهب التراثي `#d4af37` / `#f3cf65`).
- **العلامة المائية:** صورة الشعار مدمجة كخلفية مائية شفافة راقية تمنح الموقع هوية بصرية متميزة.
- **التجاوب:** متوافق 100% مع الهواتف الذكية (iOS & Android)، الأجهزة اللوحية، والشاشات الكبيرة.
